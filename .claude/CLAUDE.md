# LyClaw 项目指南

## agent-eyes GUI 操作能力

本项目配置了 **agent-eyes** MCP 服务器，你可以通过它查看和操作桌面 GUI。

### 可用工具

| 工具 | 作用 | 示例 |
|---|---|---|
| `eyes_get_tree` | 读取当前活动窗口的 UI 结构树 | 查看界面上有什么按钮、输入框 |
| `eyes_screenshot` | 截取屏幕截图 | 看当前界面长什么样 |
| `eyes_click` | 点击指定坐标或元素 | 点击"登录"按钮 |
| `eyes_type` | 在焦点位置输入文字 | 输入用户名密码 |
| `eyes_find` | 搜索界面上的元素 | 找"搜索框"在哪 |
| `eyes_list_apps` | 列出正在运行的窗口 | 看开了哪些应用 |

### 使用场景

- **桌面软件操作**: "打开微信，点击登录按钮，输入账号"
- **浏览器自动化**: "打开 Chrome，搜索 XXX"
- **界面分析**: "看看这个窗口有哪些可点击的元素"
- **填写表单**: "在第一个输入框填入名字，第二个填入密码"

### 注意

- 需要桌面环境有 AT-SPI2 无障碍服务（Linux 默认开启）
- 操作时不要移动鼠标或点击，避免干扰
- `eyes_get_tree` 返回的是界面元素的文字结构树，不是截图
