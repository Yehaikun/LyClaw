# Chat 页面布局与 Agent 进度集成设计

## 当前 ChatView 的问题

```
┌────────────────────────────────────────────┐
│  消息输入框                                  │
│  消息列表                                    │
│  (发送后白屏等 LLM 几十秒返回)               │
│                                            │
│  ❌ 没有进度展示                             │
│  ❌ 没有子Agent调用树                        │
│  ❌ 没有等待状态动画                         │
└────────────────────────────────────────────┘
```

┌─────────────────────────────────────────────────────────┐

│                            │                            │
│  ┌──────────────────────┐  │  ┌──────────────────────┐  │
│  │ 用户: 帮我审查这个PR  │  │  │ 执行中               │  │

│                            │  │  [→] search   30%   │  │

│  │                      │  │                            │
│  │  ═══ 子Agent展开 ═══  │  │  ┌──────────────────────┐  │

## 三种等待状态

### 1. 空闲状态（未发消息）

```
┌─────────────────────────┐
│   欢迎！                 │
│                          │
│   💬 输入消息开始对话     │
│                          │
│   🌐 当前 3 个 Agent 在线 │
│   🔧 2 个工具可用        │
└─────────────────────────┘
```

### 2. 等待 Agent 响应（消息已发，AI 工作中）

```
┌─────────────────────────┐
│  AI 正在处理你的请求...   │
│                          │
│  ◌ code-reviewer  审查代码  60%  ██████░░░░
│  ◌ search         搜索文档  30%  ███░░░░░░░
│  ◌ linter         等待中    0%  ░░░░░░░░░░
│                          │
│  ⏱ 已等待 12s           │
└─────────────────────────┘
```

### 3. 子 Agent 展开（点击可展开/收起）

```
┌─────────────────────────┐
│  ▶ code-reviewer (点击展开)│
│                          │
│  ┌─────────────────────┐ │
│  │ reviewer            │ │
│  │ ├─ 🔍 获取 diff ✅  │ │
│  │ ├─ 🔍 ESLint   ✅  │ │
│  │ └─ 📝 报告    ⏳   │ │
│  │ (子Agent独立对话)    │ │
│  └─────────────────────┘ │
└─────────────────────────┘
```

## 右侧面板组件

```
AgentExecSidebar.vue
├── 标题: "Agent 执行状态" + 连接指示器
├── 活跃 Agent 列表（按最近活动排序）
│   ├── Agent 头像 + 名称
│   ├── 进度条 + 百分比
│   ├── 当前阶段文字
│   └── 展开/收起子步骤
├── 已完成列表（灰色）
│   ├── Agent 名称 + 耗时
│   └── 结果摘要
└── 底部: 总体进度
```

## 实现步骤

| Step | 内容 |
|------|------|
| 1 | 创建 `AgentExecSidebar.vue` 右侧面板组件 |
| 2 | ChatView 布局改为左右两栏 |
| 3 | 消息发送时自动连接 SSE |
| 4 | 消息接收后加载会话树 |
| 5 | 等待状态动画 |
| 6 | 子 Agent 展开/收起交互 |
