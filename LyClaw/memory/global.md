Web与超文本n- **HTTP/1.1、HTTP/2、HTTP/3** — 超文本传输协议，Web 的基础。HTTP/3 基于 QUIC（UDP）。n- **HTTPS** — HTTP over TLS，加密的 Web 通信。n- **WebSocket** — 全双工、长连接协议，常用于实时推送（聊天、行情等）。n- **WebTransport** — 基于 QUIC 的新一代低延迟传输协议，可替代 WebSocket。n- **SOAP**（Simple Object Access Protocol）— 基于 XML 的 Web 服务协议，通常承载在 HTTP 上。n- **GraphQL** — 一种 API 查询语言，一般走 HTTP，但也支持其他传输。n- **REST** — 架构风格，本身不是协议，但普遍使用 HTTP。n- **WebDAV** — HTTP 扩展，用于远程文件管理、协作。n- **CalDAV / CardDAV** — 日历和联系人同步协议，基于 WebDAV。nn## 2. 流媒体与音视频n- **HLS**（HTTP Live Streaming）— Apple 的自适应流协议，基于 HTTP。n- **MPEG‑DASH** — 国际标准的动态自适应流，基于 HTTP。n- **RTSP**（Real Time Streaming Protocol）— 实时流控制协议，常用于 IP 摄像头。n- **RTP / RTCP**（Real-time Transport Protocol / Control）— 实时音视频数据传输与质量监控。n- **SIP**（Session Initiation Protocol）— 会话发起协议，用于 VoIP、视频通话信令。n- **H.323** — 视频会议早期标准簇，包含 H.225、H.245 等。n- **RTMP** — Adobe 实时消息协议，曾广泛用于直播。n- **SRT**（Secure Reliable Transport）— 开源低延迟视频传输协议，抗丢包。n- **NDI** — NewTek 的网络视频协议，用于专业视频制作。n- **WebRTC**（浏览器实时通信，信令可用 SIP/自定义，媒体用 SRTP/SCTP）nn## 3. 邮件n- **SMTP** — 简单邮件传输协议，发送邮件。n- **POP3** — 邮局协议第 3 版，下载邮件到本地。n- **IMAP4** — 互联网消息访问协议，在线管理邮件。n- **MIME** — 邮件扩展，支持附件和多部分内容。nn## 4. 文件传输与共享n- **FTP** — 文件传输协议。n- **FTPS** — FTP over SSL/TLS。n- **SFTP** — SSH File Transfer Protocol，基于 SSH。n- **TFTP** — 简单文件传输协议（UDP，常用于无盘启动）。n- **SMB/CIFS** — 微软的共享文件协议。n- **NFS** — 网络文件系统（Unix/Linux 环境）。n- **AFP** — Apple 文件协议（已被 SMB 取代）。n- **rsync** — 高效文件同步算法与协议，常用 SSH 隧道。nn## 5. 远程访问与桌面n- **Telnet** — 明文远程登录协议。n- **SSH**（Secure Shell）— 加密的远程登录与命令执行。n- **RDP** — 微软远程桌面协议。n- **VNC**（RFB 协议）— 远程帧缓冲，跨平台远程桌面。n- **X11 forwarding** — 通过 SSH 转发图形界面。n- **ICA / HDX** — Citrix 虚拟桌面协议。n- **PCoIP** — VMware / Teradici 桌面虚拟化协议。nn## 6. 域名、地址与时间n- **DNS** — 域名系统，解析域名到 IP。n- **mDNS** — 多播 DNS（Apple Bonjour / 零配置）。n- **LLMNR** — 链路本地多播名称解析（微软的零配置）。n- **DHCP** — 动态主机配置协议，自动分配 IP。n- **BOOTP** — DHCP 的前身。n- **NTP** — 网络时间协议，同步时钟。nn## 7. 目录服务与认证n- **LDAP** — 轻量级目录访问协议，如 Active Directory、OpenLDAP。n- **Kerberos** — 网络认证协议，基于票据。n- **RADIUS** — 远程拨号用户认证服务，常用于 WiFi 认证。n- **Diameter** — RADIUS 的升级版（LTE/4G 核心网用）。n- **TACACS+** — Cisco 设备管理认证协议。n- **OAuth 2.0** — 授权框架，通常走 HTTP。n- **OpenID Connect** — 基于 OAuth2.0 的身份层。nn## 8. 网络管理与监控n- **SNMP**（v1/v2c/v3）— 简单网络管理协议。n- **Syslog** — 系统日志转发协议。n- **NetFlow / IPFIX** — 流量统计导出协议。n- **sFlow** — 交换机流量采样协议。nn## 9. 即时通讯与发布/订阅n- **XMPP**（Jabber）— 可扩展消息与出席协议，用于聊天。n- **MQTT** — 轻量级发布/订阅协议，物联网标配。n- **AMQP** — 高级消息队列协议（RabbitMQ 使用）。n- **STOMP** — 简单文本导向消息协议。n- **Matrix** — 联邦式实时通信协议，底层用 HTTP/WebSocket。n- **IRC** — 互联网中继聊天协议。n- **SIP/SIMPLE** — 基于 SIP 的即时消息。n- **Kafka 自定义协议** — Apache Kafka 的 wire protocol。nn## 10. 远程过程调用（RPC）n- **gRPC** — Google 的高性能 RPC，基于 HTTP/2 和 Protocol Buffers。n- **JSON-RPC** — 无状态、轻量级 RPC，编码为 JSON。n- **XML-RPC** — 古老的 XML RPC 协议。n- **Apache Thrift** — Facebook 的跨语言 RPC 框架与协议。n- **Avro RPC** — 基于 Avro 序列化的 RPC。n- **CORBA/IIOP** — 通用对象请求代理体系，多语言中间件。n- **Java RMI（JRMP）** — Java 远程方法调用协议。n- **Dubbo** — 阿里分布式服务框架，自定义协议。nn## 11. 数据库与缓存n- **MySQL 协议** — MySQL 客户端/服务器通信协议。n- **PostgreSQL 协议**（Frontend/Backend）— PG 的 wire protocol。n- **MongoDB Wire Protocol** — MongoDB 的二进制通信协议。n- **Redis RESP** — Redis 的序列化协议。n- **Microsoft TDS** — SQL Server 表格数据流协议。n- **Oracle Net（TNS）** — Oracle 数据库连接协议。n- **Cassandra CQL Binary Protocol** — Apache Cassandra 客户端协议。nn## 12. 物联网与工业控制n- **CoAP**（Constrained Application Protocol）— 受限应用协议，类 HTTP，基于 UDP，适合低功耗设备。n- **MQTT**（已在前面提到）n- **DDS** — 数据分发服务，用于实时分布式系统（工业、自动驾驶）。n- **OPC UA** — 工业互操作性协议，支持加密、建模。n- **Modbus TCP** — 传统工控协议，用于 PLC。n- **EtherNet/IP** — 基于 CIP 的工业以太网协议。n- **PROFINET** — 西门子工业以太网标准。n- **BACnet/IP** — 楼宇自控协议。n- **DNP3** — 电力系统远动协议。n- **IEC 61850** — 变电站自动化通信标准。nn## 13. 金融交易n- **FIX**（Financial Information eXchange）— 金融信息交换协议，证券交易。n- **SWIFT MT/MX** — 银行间金融电文，基于 SWIFTNet。nn## 14. 区块链与 P2Pn- **Bitcoin 协议** — 比特币网络节点通信协议。n- **Ethereum wire protocol** — 以太坊节点之间的通信标准。n- **libp2p** — IPFS、以太坊 2.0 等使用的模块化 P2P 协议栈。n- **BitTorrent** — 文件分发 P2P 协议。nn## 15. 打印与扫描n- **IPP**（Internet Printing Protocol）— 网络打印，基于 HTTP。nn## 16. 新闻组n- **NNTP** — 网络新闻传输协议，用于 Usenet。nn## 17. 路由与基础设施（常实现为应用层，但功能特殊）n- **BGP** — 边界网关协议，TCP 179 端口，互联网核心路由。n- **RIP**（基于 UDP）— 内部网关路由协议。n- **LDP** / **RSVP-TE** — MPLS 标签分发和流量工程。nn---nn上述基本囊括了当前互联网、企业应用、物联网、工业、金融等主流领域的应用层通信协议。如果你对某类协议想深入了解或需要具体对比，可以继续问我。
