## 技术讨论记录 (2026-05-10)

**项目**: LyClaw — 本地 AI 网关应用

**讨论的技术要点**:

1. 模型抽象层设计
   - 使用策略模式 + 模板方法模式屏蔽不同厂商 API 差异
   - 已接入 MiniMax 和 DeepSeek

2. 存储层设计
   - 使用 JSON 文件存储，轻量级方案
   - 支持会话、配置、记忆、定时任务四种数据类型

3. 记忆系统
   - 短期记忆: 会话级别的消息历史
   - 长期记忆: 跨会话的 MEMORY.md
   - 支持新会话加载记忆进行上下文恢复

4. 流式响应
   - 使用 SSE (Server-Sent Events) 实现逐 token 输出
   - 基于 Reactor Flux 封装异步流式处理

5. 扩展性设计
   - 新增厂商适配器只需新建类，0 行已有代码改动
   - MCP 协议支持工具热插拔
