# 🦞 LyClaw

> **LyClaw** —— 轻量级多模型适配框架，统一对接 DeepSeek、MiniMax、OpenAI 等大语言模型。

---

## ✨ 特性

- 🎯 **统一接口**：屏蔽不同模型 API 差异
- 🧩 **模块化设计**：adapter / core / storage 分层清晰
- 💾 **灵活存储**：支持本地文件 / JSON / Markdown 多种格式
- ⏰ **定时任务**：内置 CronJob 管理
- 🔌 **易扩展**：新增模型只需实现一个 Adapter
