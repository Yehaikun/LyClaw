## 调研背景

我正在开发LyClaw——一个Java+Spring Boot的AI Agent平台。当前技术栈：
- 后端: Java 21 + Spring Boot 3.x + SQLite (JSONL存储会话)
- 前端: Vue 3 + TypeScript + Pinia
- Agent机制: @Agent注解 → JDK动态代理 → 5 Stage Pipeline → ReAct循环
- 子Agent委派: DelegateToAgentToolProvider + SubagentSpawner（代码完成度95%）
- 工具系统: ToolProvider SPI（Java原生工具扩展）
- 记忆系统: 待重新设计（会加入RAG知识库）

当前已完成子Agent模型和委派基础设施，准备进入Agent CRUD和编排雏形阶段。长远目标是：
- 用户手动创建多种类型的Agent（代码审查员、测试生成器、文档写手…）
- Agent之间可以委派子Agent协作完成任务
- Agent能够自动生成临时/持久的子Agent
- 子Agent拥有完整的上下文机制和独立记忆
- 最终形成多Agent协作网络（"Agent社会"）
